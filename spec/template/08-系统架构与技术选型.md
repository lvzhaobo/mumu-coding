## 2. 后端分层结构

> 每层写清"允许做什么、禁止做什么"。

| 层 | 文件 | 允许做 | 禁止做 |
|----|------|--------|--------|
| **Route** | 【填写：路由文件】 | 参数校验、HTTP 状态码、traceId | 直接读写存储、调用外部服务 |
| **Service** | 【填写：业务逻辑文件】 | 业务编排、结果组装 | 感知 HTTP 请求/响应 |
| **Provider** | 【填写：外部服务封装文件】 | 调用外部 API | 操作本地存储 |
| **Storage** | 【填写：存储层文件】 | 数据 CRUD、数据校验 | 调用外部 API |
