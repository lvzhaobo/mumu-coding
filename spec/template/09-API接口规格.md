## 2. 统一响应规范

### 成功响应

```json
{ "traceId": "tr_abc123...", /* 业务字段 */ }
```

### 错误响应

```json
{ "error": { "code": "ERROR_CODE", "message": "错误描述", "details": {}, "traceId": "tr_..." } }
```

### 错误码清单

| HTTP | error.code | 触发条件 | details |
|------|-----------|----------|---------|
| 400 | `EMPTY_QUERY` | 【填写：触发条件】 | `{}` |
| 400 | `INVALID_QUERY` | 【填写：触发条件】 | 【details】 |
| 【补充】 | 【错误码】 | 【触发条件】 | 【details】 |
