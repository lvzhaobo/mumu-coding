## 2. 核心功能区域 1 — 活动配置管理

> 对齐 `05` US-001 / US-004。

| 功能 | 触发方式 | 调用接口 | 行为描述 |
|------|----------|----------|----------|
| 查看活动列表 | 页面加载 | GET /api/v1/promotion/activities | 展示所有活动，按状态分组（草稿/待审批/进行中/已结束） |
| 创建活动 | 点击"新建"按钮 | POST /api/v1/promotion/activities | 打开配置表单，填写活动信息 |
| 编辑活动 | 点击"编辑"按钮 | PUT /api/v1/promotion/activities/{id} | 加载已有配置，允许修改 |
| 预览活动 | 点击"预览"按钮 | GET /api/v1/promotion/activities/{id}/preview | 在弹窗中展示活动效果预览 |
| 提交审核 | 点击"提交审核"按钮 | PUT /api/v1/promotion/activities/{id}/submit | 活动状态变为"待审批" |
| 审批活动 | 审核员点击"通过"/"拒绝" | PUT /api/v1/promotion/activities/{id}/approve | 更新活动状态，通过则进入待生效 |
| 删除活动 | 点击"删除"按钮 | DELETE /api/v1/promotion/activities/{id} | 删除草稿或已结束的活动 |

## 3. 核心功能区域 2 — 优惠券管理

> 对齐 `05` US-002 / US-006。

### 3.1 优惠券列表状态

| 状态 | 条件 | 显示内容 |
|------|------|----------|
| **A 可领取** | 活动进行中，库存充足，用户未达到领取上限 | 显示优惠券信息 + "立即领取"按钮 |
| **B 已领取** | 用户已领取该优惠券 | 显示"已领取"标签 + 优惠券信息 |
| **C 已使用** | 用户已使用该优惠券 | 显示"已使用"标签 + 使用时间 |
| **D 已过期** | 优惠券已过有效期 | 显示"已过期"标签 + 灰色样式 |
| **E 已抢光** | 优惠券库存为0 | 显示"已抢光"标签 + 灰色样式 |

### 3.2 优惠券类型

| 类型字段值 | 显示文本 | 样式 |
|------------|----------|------|
| `FULL_REDUCTION` | 满减券 | 红色标签 |
| `DISCOUNT` | 折扣券 | 橙色标签 |
| `FREE_SHIPPING` | 免邮券 | 绿色标签 |

### 3.3 用户领取流程

```
用户点击领取 → 调用领取接口 → 成功：显示"领取成功"提示，按钮变为"已领取"
                            → 失败：显示错误提示（库存不足/已达上限）
```

## 4. 核心功能区域 3 — 订单结算

> 对齐 `05` US-003。

| 功能 | 触发方式 | 调用接口 | 行为描述 |
|------|----------|----------|----------|
| 计算优惠 | 进入结算页/商品变更 | POST /api/v1/promotion/orders/calculate | 自动计算满减和优惠券优惠 |
| 选择优惠券 | 点击优惠券列表 | - | 切换使用的优惠券 |
| 智能推荐 | 计算优惠时 | POST /api/v1/promotion/coupons/recommend | 默认选中最优优惠券 |
| 提交订单 | 点击"提交订单"按钮 | POST /api/v1/promotion/orders | 创建订单，核销优惠券 |

### 4.1 优惠计算规则

> **规则说明（04 R-07）**：本系统采用"每满即减"规则，非"满一次减一次"。即商品金额超过满减门槛后，每达到一个门槛单位即触发一次减免，上不封顶。
>
> 两种常见满减语义对比：
> | 语义 | 满300减50，商品650元 | 说明 |
> |------|---------------------|------|
> | **满X减Y** | 减50元（只减一次） | 超过门槛只触发一轮 |
> | **每满X减Y**（本系统） | **减100元** | 每达到一个门槛减一次，上不封顶 |

```
应付金额 = 商品金额 - 满减金额 - 优惠券金额

满减金额计算：floor(商品金额 / 满减阈值) × 满减金额
示例：商品金额650元，满300减50
满减金额 = floor(650 / 300) × 50 = 2 × 50 = 100元
```

## 5. 核心功能区域 4 — 实时数据看板

> 对齐 `05` US-005。

| 功能 | 触发方式 | 调用接口 | 行为描述 |
|------|----------|----------|----------|
| 查看指标 | 页面加载/自动刷新 | GET /api/v1/promotion/dashboard | 展示订单量、销售额、转化率等 |
| 时间筛选 | 选择时间维度 | GET /api/v1/promotion/dashboard?timeRange=xxx | 切换实时/今日/本周数据 |
| 导出数据 | 点击"导出"按钮 | GET /api/v1/promotion/dashboard/export | 导出Excel文件 |

### 5.1 展示指标

| 指标 | 计算方式 | 展示格式 |
|------|----------|----------|
| 订单量 | 活动期间订单总数 | 数字 + 趋势箭头 |
| 销售额 | 活动期间成交金额 | 金额格式 + 趋势箭头 |
| 转化率 | 下单用户数 / 访问用户数 | 百分比 + 趋势箭头 |
| 优惠券使用率 | 使用优惠券订单数 / 总订单数 | 百分比 |
| 平均客单价 | 销售额 / 订单量 | 金额格式 |

## 6. 用户输入区域

### 6.1 活动配置表单

| 元素 | 类型 | 行为 |
|------|------|------|
| 活动名称 | 文本框 | 必填，最大100字符 |
| 开始时间 | 日期时间选择器 | 必填，格式：YYYY-MM-DD HH:MM:SS |
| 结束时间 | 日期时间选择器 | 必填，必须大于开始时间 |
| 活动类型 | 下拉框 | 可选：满减活动/优惠券活动/混合活动 |
| 满减阈值 | 数字输入框 | 仅活动类型为满减或混合时显示 |
| 满减金额 | 数字输入框 | 仅活动类型为满减或混合时显示 |
| 提交按钮 | 按钮 | 表单校验通过前禁用 |

### 6.2 优惠券配置表单

| 元素 | 类型 | 行为 |
|------|------|------|
| 优惠券名称 | 文本框 | 必填，最大50字符 |
| 优惠券类型 | 下拉框 | 可选：满减券/折扣券/免邮券 |
| 折扣金额/比例 | 数字输入框 | 根据类型显示（满减券填金额，折扣券填比例） |
| 最低消费 | 数字输入框 | 满减券必填 |
| 总库存 | 数字输入框 | 必填，大于0 |
| 每人限领 | 数字输入框 | 必填，默认3 |
| 有效期天数 | 数字输入框 | 必填，默认7 |

## 7. 错误处理与用户反馈

| 后端错误码 | HTTP | 前端展示 |
|------------|------|----------|
| `COUPON_NOT_FOUND` | 404 | 弹窗提示："优惠券不存在" |
| `COUPON_OUT_OF_STOCK` | 400 | 弹窗提示："优惠券已抢光" |
| `COUPON_LIMIT_REACHED` | 400 | 弹窗提示："您已达到领取上限" |
| `COUPON_EXPIRED` | 400 | 弹窗提示："优惠券已过期" |
| `ACTIVITY_NOT_APPROVED` | 400 | 弹窗提示："活动尚未通过审批" |
| `ACTIVITY_NOT_STARTED` | 400 | 弹窗提示："活动尚未开始" |
| `INVALID_PARAMETER` | 400 | 表单内联提示具体错误字段 |
| `INTERNAL_ERROR` | 500 | 弹窗提示："系统繁忙，请稍后重试" |
