## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| 优惠券领取接口 P95 延迟 | < 200ms | Prometheus + Grafana | `05` US-002 |
| 订单优惠计算接口 P95 延迟 | < 300ms | Prometheus + Grafana | `05` US-003 |
| 实时数据看板查询 P95 延迟 | < 500ms | Prometheus + Grafana | `05` US-005 |
| 活动配置提交 P95 延迟 | < 1s | Prometheus + Grafana | `05` US-001 |
| 首页活动展示 P95 延迟 | < 1.5s | 前端性能监控 | 用户体验 |

### 1.2 降级策略

| 级别 | 触发条件 | 降级行为 | 用户感知 |
|------|----------|----------|----------|
| **级别 1 — 限流降级** | QPS > 5000 或 CPU > 80% | 限制新请求进入，返回排队提示 | 部分用户需等待重试 |
| **级别 2 — 缓存降级** | Redis 不可用或响应延迟 > 500ms | 使用本地缓存数据 | 数据可能有5分钟延迟 |
| **级别 3 — 只读模式** | 数据库写入失败或主从延迟 > 10s | 暂停优惠券领取，仅支持查询 | 优惠券领取按钮置灰 |
| **级别 4 — 静态页面降级** | 核心服务宕机 | 切换到静态活动页面 | 无法领取优惠券，可浏览商品 |

| 约束 | 说明 |
|------|------|
| 降级顺序 | 必须按级别顺序降级，不可跳级 |
| 降级通知 | 降级时显示友好提示，告知用户当前状态 |
| 兜底方案 | 最差情况下用户可浏览活动页面，但无法领取和使用优惠券 |

### 1.3 容量规划

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 峰值 QPS | 5000 | 大促期间预期峰值 |
| 并发用户数 | 10000 | 同时在线用户数 |
| 优惠券领取峰值 | 1000/秒 | 秒杀场景 |

## 2. 可用性需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | 99.9% | 大促活动期间 |
| MTTR | < 5 分钟 | 核心故障恢复时间 |
| 数据一致性 | 最终一致性 | 优惠券库存允许短暂不一致，5秒内恢复 |

### 2.1 故障模式与恢复

| 故障类型 | 恢复方式 | RTO | RPO |
|----------|----------|-----|-----|
| 应用服务进程故障 | 容器自动重启（K8s健康检查） | < 1分钟 | 0 |
| 数据库主库故障 | 自动切换到从库 | < 1分钟 | < 5秒 |
| Redis 故障 | 降级到数据库直接读取 | < 1分钟 | 0 |
| RocketMQ 故障 | 本地消息持久化 + 重试机制 | < 5分钟 | < 5秒 |

## 3. 可观测性需求

### 3.1 链路追踪

| 项 | 规格 |
|----|------|
| traceId 格式 | `tr_{uuid.hex}` |
| 注入位置 | 所有成功响应顶层 + 错误响应 `error.traceId` |
| 上游透传 | 优先复用请求头 `X-Trace-Id`，缺省时本地生成 |
| 采样率 | 100%（活动期间）|

### 3.2 错误码体系

| HTTP | `error.code` | 触发条件 |
|------|--------------|----------|
| 400 | `EMPTY_QUERY` | 请求参数为空 |
| 400 | `INVALID_QUERY` | 请求参数格式错误或校验失败 |
| 400 | `COUPON_OUT_OF_STOCK` | 优惠券库存不足 |
| 400 | `COUPON_LIMIT_REACHED` | 用户已达到领取上限 |
| 401 | `UNAUTHORIZED` | 未登录或 token 失效 |
| 403 | `FORBIDDEN` | 无操作权限 |
| 404 | `COUPON_NOT_FOUND` | 优惠券不存在 |
| 404 | `ACTIVITY_NOT_FOUND` | 活动不存在 |
| 409 | `ACTIVITY_ALREADY_APPROVED` | 活动已通过审批，无法修改 |
| 500 | `INTERNAL_ERROR` | 系统内部错误 |
| 502 | `UPSTREAM_ERROR` | 依赖服务不可用 |
| 503 | `SERVICE_UNAVAILABLE` | 服务降级或维护中 |

### 3.3 日志规范

| 日志级别 | 使用场景 | 示例 |
|----------|----------|------|
| DEBUG | 详细调试信息 | 优惠计算过程、缓存命中情况 |
| INFO | 正常业务流程 | 优惠券领取成功、订单创建成功 |
| WARN | 需要关注的异常情况 | 库存不足警告、降级触发 |
| ERROR | 错误但不影响系统运行 | 优惠券领取失败、接口调用失败 |
| FATAL | 致命错误，系统可能崩溃 | 数据库连接池耗尽 |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | JWT Token | 用户登录后获取 token，请求时携带 |
| CORS | 白名单机制 | 仅允许前端域名访问 |
| 速率限制 | Token Bucket | 单用户领取接口：5次/分钟；下单接口：10次/分钟 |
| 防刷机制 | Redis 计数 + 验证码 | 高频请求触发图片验证码 |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 |
|----------|----------|
| 用户密码 | BCrypt 加密存储，不可逆 |
| JWT Token | 短期有效期（2小时），支持刷新 |
| 用户手机号 | 脱敏显示（中间4位用*代替） |
| 用户地址 | 加密存储，传输加密 |
| 订单金额 | 数据库加密存储 |

### 4.2 权限控制

| 角色 | 权限 |
|------|------|
| 超级管理员 | 所有操作权限 |
| 运营专员 | 创建/编辑活动、查看数据 |
| 审核员 | 审批活动配置 |
| 只读用户 | 仅查看权限 |
