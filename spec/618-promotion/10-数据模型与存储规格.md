## 1. 概念模型

```
Activity (活动) 1 ── * Coupon (优惠券)
    │                        │
    │  id (PK)               │  id (PK)
    │  name                  │  activity_id (FK → Activity)
    │  start_time            │  name
    │  end_time              │  type
    │  status                │  discount_value
    │  type                  │  total_stock
    │                        │  remaining_stock
    │                        └  limit_per_user
         │
         │
         ▼
UserCoupon (用户优惠券) * ── 1 User (用户)
    │                        │
    │  id (PK)               │  id (PK)
    │  user_id (FK → User)   │  level
    │  coupon_id (FK → Coupon)
    │  status
    │  receive_time
    │  expire_time
    └  used_time
```

> **核心关系**：一个活动可包含多个优惠券；一个用户可拥有多张优惠券；一张优惠券可被多个用户领取。

## 2. 存储引擎

| 项 | 说明 |
|----|------|
| 引擎 | MySQL 8.0.33 |
| 编码 | UTF-8 |
| 读写模式 | 主从复制，主库写，从库读 |
| 并发安全 | InnoDB 事务 + 乐观锁 |
| 文件布局 | 数据库表存储，Redis 缓存热点数据 |
| 缓存层 | Redis 6.2，缓存活动配置、优惠券库存、用户优惠券 |

## 3. 实体定义 — Activity（活动）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `id` | `BIGINT` | 是 | **PK**, AUTO_INCREMENT | 活动ID |
| `name` | `VARCHAR(100)` | 是 | NOT NULL | 活动名称 |
| `description` | `VARCHAR(500)` | 否 | - | 活动描述 |
| `start_time` | `DATETIME` | 是 | NOT NULL | 开始时间 |
| `end_time` | `DATETIME` | 是 | NOT NULL | 结束时间 |
| `type` | `VARCHAR(20)` | 是 | NOT NULL, ENUM | 活动类型：FULL_REDUCTION/COUPON/MIXED |
| `full_reduction_threshold` | `DECIMAL(10,2)` | 否 | >=0 | 满减阈值 |
| `full_reduction_amount` | `DECIMAL(10,2)` | 否 | >=0 | 满减金额 |
| `status` | `VARCHAR(20)` | 是 | NOT NULL, ENUM | 状态：DRAFT/PENDING_APPROVAL/APPROVED/ACTIVE/ENDED/REJECTED |
| `created_at` | `DATETIME` | 是 | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | `DATETIME` | 是 | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |
| `created_by` | `VARCHAR(50)` | 是 | NOT NULL | 创建人 |
| `approved_by` | `VARCHAR(50)` | 否 | - | 审批人 |
| `approved_at` | `DATETIME` | 否 | - | 审批时间 |

## 10. 关键业务逻辑

| 逻辑 | 触发条件 | 行为 |
|------|----------|------|
| **优惠券领取校验** | 用户点击领取按钮 | 检查活动状态、优惠券库存、用户领取上限 |
| **库存扣减** | 用户领取成功 | 使用乐观锁扣减库存，失败则重试 |
| **优惠券过期** | 到达过期时间 | 定时任务将状态改为 EXPIRED |
| **优惠券使用** | 订单支付成功 | 核销优惠券，更新状态为 USED |
| **级联删除** | 删除活动 | 同步删除关联的优惠券和用户优惠券记录 |
| **活动状态自动变更** | 到达开始/结束时间 | 定时任务更新活动状态 |
| **满减优惠计算** | 订单结算 | floor(商品金额 / 满减阈值) × 满减金额 |
| **优惠券智能推荐** | 订单结算 | 分析用户可用优惠券，推荐优惠力度最大的 |
